# InfoStag DevOps

Internship test task - SQLite build and containerization using CMake and Docker.

## Tech Stack

- **C**
- **Docker**

## Features

- SQLite build via CMake
- Docker containerization
- CI/CD pipeline

## Getting Started

### Prerequisites

- [Docker](https://www.docker.com/)
- [CMake](https://cmake.org/)
- C compiler (GCC/Clang)

### Installation

```bash
git clone https://github.com/Br1Im/InfoStag_DevOps.git
cd InfoStag_DevOps
```

### Running

```bash
docker-compose up
```
